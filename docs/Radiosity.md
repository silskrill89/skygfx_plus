# Radiosity

#radiosity #postfx

## Overview
PS2-style radiosity approximation — pre-pass that samples and bounces light for color bleeding.

## Variants
| Variant | Description |
|---------|-------------|
| PS2 | Original PS2 approximation |
| Shader | Shader-based approximation |
| VCS | Vice City Stories variant |

## Config
```ini
radiosity=PS2|Shader|VCS
```
